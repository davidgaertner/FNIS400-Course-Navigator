# FNIS logo

The supplied First Nations and Indigenous Studies artwork is installed at:

```text
assets/fnis-logo.png
```

The header uses it automatically, preserves its aspect ratio, and does not crop or recolour it. If `fnis-logo.png` is absent or fails to load, the interface displays a compact typographic “FNIS” fallback without showing a broken image. The fallback and real logo never display together.
